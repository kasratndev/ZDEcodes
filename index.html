HOW TO IMPORT A MODEL
  1. Type a model name above, then click Find.
  2. On Poly Pizza, choose the model you want.
  3. Open its download option and download the .GLB file.
  4. Drag the downloaded GLB file into the 3D scene below.
  5. Wait for it to load, then move, scale, and rotate it.
Tip: Check the model's license and creator credit before using it in a published game.
